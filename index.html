Comment Thing

This web app lets users search for any song, podcast episode, or audiobook directly from Spotify’s catalog using the Spotify Web API. Once a piece of media is selected, users can leave comments, reply to others, and engage in conversations centered around what they’re listening to.

Designed and built the comment and reply system from scratch, handling data modeling in MongoDB and API integration with PHP on the backend.

Accessibility Refactor

This project is focused on accessibility to help myself better understand and implement inclusive design practices. I used practical resources, tools, and guidance to support accessible web development, with an emphasis on clarity, usability, and compliance with modern standards like WCAG. My goal was to help everyday users to make the web more inclusive for everyone.

Audited and refactored a web application to meet WCAG 2.1 compliance standards, addressing semantic HTML structure, keyboard navigation, screen reader compatibility, color contrast, and focus management. This reflects the accessibility-first approach I bring to all UI work — particularly relevant for regulated industries where inclusive design is both a legal requirement and a user expectation.
